# vc-serverQuickAccess
A custom Vencord userplugin that adds quick access server icons directly to the top right header wrapper bar.

## Installation
Clone this repository directly into your Vencord userplugins directory:
```bash
cd C:\Users\godpa\Vencord\src\userplugins
git clone [https://github.com/orbeez100/vc-serverQuickAccess](https://github.com/orbeez100/vc-serverQuickAccess)
pnpm build
